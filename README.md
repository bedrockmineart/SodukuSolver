# SodukuSolver

A simple command-line Python Sudoku solver.

## Requirements

- Python 3

## Usage

Run the solver:

```bash
python SodukuSolver.py
```

Then enter 81 values (one per line) in row-major order:

- Use `1` through `9` for known cells
- Use `0` for blanks

The solver will print the solved grid if it can find a solution.
